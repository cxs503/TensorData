# DTMB 5415 design-space benchmark (Zenodo 19222008) — access & integration

## What it is
9,001 configurations, column 0 = baseline DTMB 5415. `DTMB5415-database.mat` is MATLAB **5.0**
format (miCOMPRESSED) — `scipy.io.loadmat` works, `h5py` does **not**. Matrices (all 2250×9001
except variables): `xMatrix/yMatrix/zMatrix` (full-scale, half hull y≥0, 2250 points),
`variablesMatrix` (27×9001, in [-1,1]), `coefStatMatrix` (Cw), `accelerationRMSMatrix`,
`motionRMSMatrix` (rows = Fr 0.25/0.33/0.41), plus pressure/wave-elevation fields.

## Training-ready table
`python scripts/dtmb5415_dataset_pipeline.py --n-geometry 100 --seed 20261113`
writes `data/derived/dtmb5415/dtmb5415_train_ready.{csv,npz}` + `dtmb5415_splits.npz`
(80/10/10 seed-split, baseline kept as index 0), with sha256/shape/NaN accounting in
`artifacts/GAP-CAD-T2-SHIPD-5415/dtmb5415/train_ready_manifest.json`.

```python
import numpy as np
d = np.load("data/derived/dtmb5415/dtmb5415_splits.npz")
d["X_train"].shape, d["y_train"].shape      # (7200, 27), (7200, 3)  y = Cw at 3 Froude numbers
```

Learnability floor (standardized ridge, 5-fold): Cw R² = 0.037 / 0.574 / 0.331 (Fr = 0.25/0.33/0.41);
az/xi5 R² = 0.70–0.77. A floor, not a performance claim.

## Geometry gate and its limits
`artifacts/.../dtmb5415/geometry_gate.json`: point count, centreplane closure, dimensions vs the
documented baseline, and per-config perturbation vs baseline. **Not measurable** from this payload
and therefore not claimed: watertightness, enclosed volume, Cb, draft (the z-extent includes
above-water structure). The `hull-mesh` closed-manifold profile is *not* applied here.

Measured (100 sampled configs): 45/100 inside the gate; **all 55 failures are one cause —
beam deviation from baseline up to 5.0% against a 2% threshold**. Beam is a sampled design
dimension of this benchmark, so the 2% threshold is mis-specified: it measures design-space span,
not corruption. Honest status: threshold needs revision (see report §6), the data are not defective.
